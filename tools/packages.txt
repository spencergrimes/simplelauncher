# Packages to remove from the device with tools/strip.sh
#
# One package name per line. Blank lines and # comments are ignored; a trailing
# comment after a package name is fine too.
#
# EVERYTHING BELOW IS COMMENTED OUT ON PURPOSE. strip.sh does nothing until you
# uncomment lines here deliberately, and even then it dry-runs unless you pass
# --apply.
#
# Nothing here is truly deleted — `pm uninstall -k --user 0` removes the package
# for user 0 only; the system image copy stays. tools/restore.sh brings any of it
# back. See README.md.
#
# Find the exact name of something on the device:
#   adb shell pm list packages | grep -i chrome

# --- browser -------------------------------------------------------------
# Removing Chrome also removes the system WebView provider on some builds and
# can break in-app browsers. Test before you commit to this one.
#com.android.chrome

# --- media / entertainment -----------------------------------------------
#com.google.android.youtube
#com.google.android.videos                  # Google TV / Play Movies
#com.google.android.apps.youtube.music
#com.google.android.play.games              # Play Games

# --- the Google app ------------------------------------------------------
# This is the Google app / Assistant / Discover feed / "at a glance". Removing
# it kills the search bar, hotword, and the weather that Pixel Weather does not
# provide on older devices. Big change — be sure.
